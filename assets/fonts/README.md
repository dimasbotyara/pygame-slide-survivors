# Bundled typefaces

Unmodified fonts from [Google Fonts](https://github.com/google/fonts/tree/0f3edfe222bdb0b49ce0c631d677a83542ad6d5a/ofl), revision `0f3edfe222bdb0b49ce0c631d677a83542ad6d5a`. Each family directory includes its SIL Open Font License and copyright notices. No network access or system font installation is needed to play.
